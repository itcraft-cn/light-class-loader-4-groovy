# class-lambda-4-groovy4

> A Groovy4 class loader based on `Unsafe.defineAnonymousClass`: defines Groovy compilation output as "anonymous classes (class-lambda style)", avoiding the regular class-loading overhead in Metaspace.

English | [中文](README.md)

## Introduction

`class-lambda-4-groovy4` provides `GroovyLambdaClassLoader`, which extends `groovy.lang.GroovyClassLoader` and defines generated bytecode via `sun.misc.Unsafe#defineAnonymousClass` inside the compilation callback, instead of the traditional `ClassLoader#defineClass`. It also ships with an MD5-based source-code class cache so that identical scripts are not recompiled and do not repeatedly occupy Metaspace.

## Features

- **Unsafe anonymous class definition**: loads Groovy compilation output through `Unsafe#defineAnonymousClass`
- **Source-level caching**: uses the MD5 of `scriptText + codeSource` as the cache key; identical sources reuse the same `Class` instance
- **Timestamp field injection**: when `recompileGroovySource` is enabled, `__timeStamp` fields are injected so recompiled artifacts stay distinguishable
- **Privileged execution**: restricted initialization logic is wrapped with `AccessController.doPrivileged`

## Requirements

- JDK 8 (`maven.compiler.source/target = 8`, depends on `sun.misc.Unsafe`)
- Maven 3.x (or mvnd)
- Apache Groovy 4.0.x

## Quick Start

```java
CompilerConfiguration config = new CompilerConfiguration();
config.setSourceEncoding("UTF-8");

GroovyClassLoader loader = new GroovyLambdaClassLoader(
        Thread.currentThread().getContextClassLoader(), config, false);

Class<?> clazz = loader.parseClass(
        "class demo1 implements com.example.DemoInterface {\n" +
        "  def boolean demo(String name, int age){ name.length() > 5 && age > 12 }\n" +
        "}\n");

DemoInterface demo = (DemoInterface) clazz.newInstance();
demo.demo("abcdefgh", 31);
```
